# Intro-to-EPRV-Data
Here's an introductory python notebook for looking at high resolution spectra, working with different wavelengths and timeseries.

## Data files

`data_folder/time_df.csv` and `data_folder/waves_kitcat.txt` are included in this repository. The large spectral arrays `spectra_kitcat_act.npy` and `spectra_kitcat_act_err.npy` are kept locally in `data_folder/` and excluded from Git. A fresh clone requires obtaining those arrays separately.
